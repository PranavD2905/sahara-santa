Reveal song

reveal-song.mp3: "Socha Hai" from Rock On, copied from the user's supplied MP3.
The original file is unchanged (4 minutes 22 seconds). This track is separate
from the CC0 and CC BY sound effects listed above.
The song starts as the chosen card begins to flip, without a timer or an
animation-completion delay. It stops on navigation and stays muted during
the shuffle on a replay.

Global music (pending)

background.mp3 is reserved for the next user-supplied MP3. The code is ready.
It loops on all other screens and pauses for the entire Reveal screen.
If the browser blocks autoplay, the first click or tap starts the music.
The app has no mute button. A saved mute setting from older visits is reset.
