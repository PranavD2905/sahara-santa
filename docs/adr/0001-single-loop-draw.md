# The Draw is a single loop, not an arbitrary derangement

A random derangement can contain two-person swaps (A→B→A). If one of those Members later leaves, "their Santa takes over their receiver" would make the other person draw themselves. We generate one loop through all Members (respecting Exclusions) so a Patch always works. If a Patch would break an Exclusion, the Organizer is prompted to run a Re-draw instead.

## Consequences

- Fewer possible Draws than a full derangement, which is acceptable at 3–50 Members.
- Some Exclusion sets allow a derangement but no single loop; the Draw is blocked with an explanation.
